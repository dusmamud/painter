# Painter — Professional Painting Services

A mobile-first, static painting-services website built with the same stack as
[Creatix](https://github.com/dusmamud/creatix): Astro 7 + Tailwind CSS 4,
GSAP + Lenis motion, no backend, no UI library. Built from a design reference
("same to same") with AI-generated imagery, including transparent PNG cutouts.

Live: https://painter-static.pages.dev

> **All content is MOCK / demo** — brand details, phone, email, address,
> prices, testimonials, projects and team members are placeholders. Replace
> before launch.

## Stack

| Piece | Version |
| --- | --- |
| Astro (static output) | 7.4.12 |
| Tailwind CSS (CSS-first, `@tailwindcss/vite`) | 4.3.5 |
| `@astrojs/sitemap` | 3.7.5 |
| GSAP (+ ScrollTrigger) | 3.15.1 |
| Lenis smooth scroll | 1.3.27 |
| TypeScript (strict) | 7.0.2 |
| Node | ≥ 24 |

Dev-only: `sharp` (image variants), `playwright-core` (QA screenshots).
No React/Vue/Svelte, no fontsource packages — fonts are self-hosted woff2 in
`public/fonts` (Poppins 400–800, Caveat 600/700).

## Pages (13 routes, 12 sitemap URLs)

Home, Services + 4 detail pages, About, Projects, Pricing, Contact,
Privacy, Terms, 404. `/search` is intentionally not present; the 404 page is
excluded from the sitemap.

## Scripts

```bash
npm ci            # install

npm run build     # static build -> dist/
npm run preview   # serve the build
```

## Images

Masters live in `public/images/`; responsive variants are generated by
`scripts/convert-images.mjs` (sharp: WebP + JPG at 480/800/1200/1600 for
photos, 96/160 for avatars, plus OG images). Re-run it after replacing a
master — it skips already-generated variants and the white-background
originals (see the `SKIP` set in the script).

Transparent cutouts (`hero-painter-cut.png`, `chair-scene-cut.png`,
`splash-flat-cut.png`) were made from white-background generations with
`scripts/remove-white-bg.py` (luminance flood-fill from the corners + alpha
erosion + white un-multiply + trim) and `scripts/fix-enclosed-white.py`
(removes enclosed near-white regions such as the background showing through
the paint-bucket handle loop). Do not re-run `rembg` on this VM — it downloads
a 1 GB model and gets OOM-killed; the flood-fill pipeline is the final
approach.

Responsive-image rule (measured): `sizes` must be repeated on every `<source>`
**and** the `<img>` — sizes on the `<img>` alone falls back to 100vw for
`<source>` selection. `src/components/Picture.astro` handles this.

## QA

`scripts/qa-shots.mjs` serves `dist/` locally and screenshots 7 routes at
390/768/1024/1440 with Playwright, failing on horizontal overflow or console
errors. Screenshots land in `qa/shots/`. Playwright on this VM can only reach
localhost — use `curl` for live-origin checks.

## Motion

`src/scripts/motion.ts` (Lenis + GSAP reveals/count-ups, header shadow, FAQ,
project filter, mailto forms with validation + toast) is imported by the
layout frontmatter, so it also executes during prerender — its whole body is
guarded by `if (typeof window !== 'undefined')`. Do not remove the guard.

## Deploy

Push to `main` (or manual dispatch) → GitHub Actions builds and deploys `dist/`
to Cloudflare Pages project `painter-static` via wrangler. Requires the repository
secrets `CLOUDFLARE_API_TOKEN` and `CLOUDFLARE_ACCOUNT_ID`.
